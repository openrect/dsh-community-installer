# Security policy

## Supported version

Only the latest published DSH Community Installer release receives security fixes. The bundled `@deepseek-ai/dsh` runtime follows its upstream support policy.

## Reporting a vulnerability

Use the repository's private GitHub vulnerability reporting form when it is available. If private reporting is not enabled, open an issue containing only a short impact summary and a request for a private contact channel. Do not include API keys, personal data, working exploits, or sensitive local paths in a public issue.

Reports should include the affected installer version, Windows version, online or offline mode, reproduction conditions, and whether the problem occurs before or after the upstream DSH service starts.

## Distribution notes

Release executables are currently unsigned community builds. Verify the SHA-256 published with the corresponding GitHub Release. DSH Community Installer never asks users to disable SmartScreen or antivirus protection.
